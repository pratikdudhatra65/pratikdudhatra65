## 👋 About Me

I'm a **Senior Flutter Developer** with 7+ years of mobile development experience, focused on building scalable and production-ready applications across **fintech, automotive, e-commerce and enterprise** domains.

I care about clean architecture, smooth performance, maintainable code and development workflows that help teams ship reliable features efficiently.

* 🏗️ **Architecture:** Clean Architecture, BLoC, MVVM / MVC, modular design and reusable UI components
* 🔌 **Integrations:** REST & GraphQL APIs, payments & subscriptions, GPS / location, camera & media, push notifications and deep linking
* 📴 **Offline-first:** Local persistence, offline-to-online synchronization and data reconciliation
* 🚀 **Performance:** UI optimization, efficient state management, memory-conscious development and responsive user experiences
* 🤝 **Collaboration:** Feature breakdown, code reviews, technical problem solving and knowledge sharing
* 💬 **Ask me about:** Flutter, Dart, Firebase, BLoC, state management and mobile architecture
